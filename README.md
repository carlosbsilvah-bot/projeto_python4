Exercício 3 - Funções com Passagem de Parâmetros

Exercícios desenvolvidos em Python para praticar funções com passagem de parâmetros e retorno de valores.

Exercício 3a

Foi criada uma função que recebe um número inteiro como parâmetro e retorna o seu fatorial.

O programa solicita um valor ao usuário, chama a função e exibe o resultado.

Exemplo
Digite um valor: 5
120
Exercício 3b

O exercício 3b utiliza a função de fatorial desenvolvida anteriormente e acrescenta uma função de divisão, que recebe dois parâmetros inteiros.

O programa calcula a expressão:

1 + 1/1! + 1/2! + 1/3! + ... + 1/N!

O valor de N é informado pelo usuário.

Exemplo
Digite um valor: 6
2.7180555555555554

Neste exercício, também foi praticada a utilização do resultado de uma função como parâmetro para outra função.
